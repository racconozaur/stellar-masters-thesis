## 2. Trustline Projection Network LCC

### Script: `create_trust_proj_LCC_idf.py`



### Network Type

- **Network**: Trustline Projection Network (Undirected, Weighted)
- **Nodes**: Stellar account IDs (filtered to those in the transaction LCC)
- **Edges**: Shared issuer relationships between accounts
- **Edge Weights**: IDF-weighted similarity scores based on shared issuers

### Why Trustline Projection?

Trustlines in Stellar are fundamentally different from transactions:
- Trustlines form a **bipartite network**: accounts trust issuers
- Direct analysis of this bipartite structure is challenging for many algorithms
- **Projection** creates an account-to-account network that captures trust similarity
- Accounts sharing rare/distinctive issuers receive higher similarity scores (IDF weighting)

### Implementation Details

- Load Transaction LCC Accounts
- Filter and Aggregate Trustlines
- Build Indices and Compute IDF Weights
- Filter Issuers
- Build Inverted Index
- Compute Top-K Neighbors

### Input Requirements

**Input Files**:

1. **Transaction LCC** (required first):
   ```
   ../transactions/LCC_G_tx_undirected_weighted.pkl
   ```
   - Generated by `create-transaction-lcc.py`
   - Used to filter accounts to transaction LCC

2. **Trustlines CSV**:
   ```
   ~/stellar-clustering/network/data/trustline_edges_mv.csv
   ```

**Trustlines CSV Format**:
```csv
account_id,issuer_id,asset_code,balance
123456789,987654321,USD,1000.50
123456789,111111111,EUR,500.00
...
```

**Columns**:
- `account_id`: Stellar account ID (integer)
- `issuer_id`: Token issuer account ID (integer)
- `asset_code`: Asset/token code (e.g., "USD", "EUR", "BTC")
- `balance`: Trustline balance (float)
